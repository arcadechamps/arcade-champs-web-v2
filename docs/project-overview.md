1. Project Overview
Arcade Champs is a skill-based gaming contest platform centered on retro emulation games (e.g., NES, SNES, arcade classics, Windows 95-era titles like 3D Pinball Space Cadet).  The platform will consist of two interconnected websites:
- Existing Site (WordPress)  
  - User account creation, funding, and management  
  - Handles payments, prize distribution, and admin notifications
- New Adjoining Site (Custom Web App)  
  - Web-based emulator with a free-play library of ROMs  
  - Pay-to-play contest mode for select games  
  - Leaderboards, time-limited play, anti-cheating, and automated scoring

---
2. Core Vision
Enable users to:
- Play retro games for free in-browser (no registration required for casual play)
- Enter paid contests (e.g., $1 to win $500) on select games
- Compete fairly under strict time limits (e.g., 10 minutes per entry)
- View real-time leaderboards
- Receive automated prize payouts via email upon contest close
“Playing the percentages” — High-volume micro-entries fund large prize pools.
